# Home assistant add-on

## Tech Stack & Environment

- Language: Python / Typescript (or Javascript where required)
- Target playform: Home Assistant HACS repository

## Project aim

The project aims to create an integration with Home Assistant which can pull in data from multiple sources and display nicely in the Home Assistant platform.

# Data sensors

Data sensors should support aggregated workout data. Eg: Running, Cycling or Walking hours, kms and miles per day, week, month, year.

# Data display

The add-on should support the display of workout data plotted against the previous period. Eg: This month vs last month but also support this current years km/miles/hours vs last years. This should be plotted in a graph form.

## Data source support

The main aim is to support Garmin data and Strava data sources.
